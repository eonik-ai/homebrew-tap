# eonik for Mac

Finished, on-brand ads — without the busywork.
[eonik.ai](https://www.eonik.ai)

## Install

```sh
brew install --cask eonik-ai/tap/eonik
```

Or, without Homebrew:

```sh
curl -fsSL https://eonik.ai/install | sh
```

Either way, eonik lands in your Applications folder and keeps itself up to date.

## Requirements

macOS 15 (Sequoia) or later, on Apple silicon or Intel.

## Uninstall

```sh
brew uninstall --cask eonik
```

To remove your projects, generated clips and settings as well:

```sh
brew uninstall --zap --cask eonik
```
